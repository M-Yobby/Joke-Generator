# 😂 Joke Generator

This is a simple Python program that generates random dad jokes.  
The user can type **'Haha'** to get a random joke or **'exit'** to quit the program.

---

## 📌 Features
- Displays a **random joke** from a predefined list.
- Allows users to **keep generating jokes** until they choose to exit.
- Fun and simple **command-line interface**.

---

## 🖥️ Example Usage
```
Welcome to the Joke Generator!
Type 'Haha' to get a joke or type 'exit' to quit: Haha
Why did the scarecrow win an award? Because he was outstanding in his field.

Type 'Haha' to get a joke or type 'exit' to quit: Haha
I asked my dog what’s two minus two. He said nothing.

Type 'Haha' to get a joke or type 'exit' to quit: exit
Thanks for using the Joke Generator! Goodbye!
```

---

## ▶️ How to Run in VS Code
1. Make sure **Python** is installed on your computer.
2. Install **VS Code** and the **Python extension**.
3. Save this script as `joke_generator.py`.
4. Open **VS Code** and navigate to the folder containing the script.
5. Open the script file in VS Code.
6. Click **Run** ▶ at the top-right corner or press **Ctrl+F5** to run the program.
7. Follow the prompts in the **Terminal**.
